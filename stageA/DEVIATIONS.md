# Deviations from the frozen protocol and test split

Log every change made after `docs/FROZEN_TEST_SET.json` was written (2026-10-01), with the date, what
changed, why, and which results it affects. `python scripts/freeze_test_set.py --verify` must pass before
any test-split run; the run scripts refuse to start on the test split otherwise.

| 2026-10-01 | **Compaction rule (harness v0.3).** Compaction now happens at the first of: the template's compaction step (or a revocation, for `after_revocation` templates), or the moment the agent is about to end the task (a `finish` call, or the last text-only reply allowed), once it has made at least 2 tool calls. The intercepted `finish` is not executed and is not kept in the writer's context. Each trajectory records `compaction_reason` (`step` / `revocation` / `before_finish`); results are reported overall and by reason. `--fixed-step-only` restores the v0.2 rule. | First capability screen on dev (jobs 112207, 112208): Qwen3-8B finished before the compaction step in 18/30 runs (2 to 7 tool calls, step 6 to 8). Checking the frozen test set afterwards: in 49/60 test templates the shortest correct path ends before the compaction step, so most test runs would never compact. Chosen by the PI over lowering the steps or lengthening the tasks, because it changes no template. | All runs. No test-split run existed. Test instances are unchanged (fingerprint verified). 4 test templates (T-P15, T-C12, T-C15, T-C18) can be solved with one write; an agent that does only that still finishes before compaction (listed in `tests/test_v03.py`). |
| 2026-10-01 | **Reasoning sent back between turns.** Each assistant message now carries the turn's `reasoning`, which vLLM 0.30.0 renders as `<think>` (Qwen3 template) or as harmony analysis messages (gpt-oss). `--no-keep-reasoning` restores v0.2. | gpt-oss-20b, same screen: 8/30 runs ended in HTTP 500 (`HarmonyError: unexpected tokens remaining in message header`) and 17/22 of the rest had tool names with format tokens (`finish<\|channel\|>commentary`). None of this happened on the first turn (0/22); it started once there was history without reasoning. Both models' chat formats keep reasoning within a multi-step tool sequence. | All runs. What each model sees follows its own chat format. During the task, both see their earlier reasoning within the tool sequence.
